# Ao Oni (아오오니) — 림월드 모드 도감

RimWorld 1.6 / Anomaly DLC. 클래식 호러 게임 『아오오니』의 푸른 악마가 림월드를 유린합니다.
이 문서는 모드에 구현된 모든 오니와 시스템을 정리한 도감입니다.

---

## 감염 — 오니의 저주

오니의 상처를 입은 생명체는 그것이 사람이든, 동물이든, 심지어 메카노이드든 감염됩니다.

| 항목 | 내용 |
|---|---|
| 감염 확률 | **70%** (방어구가 데미지를 완전히 막았으면 감염 없음) |
| 잠복 기간 | **3일** — 외견상 완전히 정상, 건강 탭에서도 보이지 않음 |
| 변화 예고 | 변이 **4시간 전**부터 피부가 보라색으로 변함 |
| 변이 | 잠복기가 끝나면 피해자는 무작위 변종 오니로 변신 |
| 진단 | 연구 「아오오니 감염 검사」 후 **외과 검사**(Anomaly 기본 수술)로 발각 — 감염·도플갱어 모두 탐지 |
| 치료 | 연구 「아오오니 치료」 후 **외과 수술**(공업 의약품 4개, 생약 불가). 메카노이드는 **수리 중 자동 정화** |

- **특수 감염**: 좀비 오니 물기는 100% 감염 + 잠복기 1.5일 / 박쥐 오니 물기는 광란 감염으로 **4시간** 만에 변이
- **블루베리 가스**: 뚱오니가 죽으며 내뿜는 보라색 가스에 심각하게 노출되면 폐부패와 동일한 확률 곡선으로 감염
- 메카노이드 감염은 모드 설정에서 끌 수 있습니다.
- **치료 수단**:
  - 외과 수술 「아오오니 치료」 (연구 필요, 공업 의약품 4) — 메카노이드는 수리 중 자동 정화
  - **회복 혈청(healer mech serum)** — 최악의 건강 상태로 감염을 취급해 치료
  - **부자연적 치료(Anomaly psycast)** — 동일하게 감염을 치료
  - **루시페륨** — 복용 중에는 오니 감염에 **면역**(감염 시도가 즉시 무효화되고, 이미 있는 감염도 치료됨). 메카노이드에는 효과 없음
- 감염된 정착민은 결국 오니가 됩니다. 정착민이 사라지고 그 자리에서 오니가 일어납니다.

---

## 오니 도감

기본 스펙(아오오니): 체력 **걸신의 2배**, 이동속도 5.0 c/s, 물기/할퀴기(날카로움).
표기되지 않은 능력치는 아오오니를 따릅니다. 오니의 시체는 **뒤틀린 고기**와 **오니 가죽**을 남깁니다.

### 기본

**아오오니 (Ao Oni)**
거대한 푸른 살덩이의 악마. 감염의 근원이자 모든 변종의 원형.

|---|---|

| **아메바 오니** | 사거리 20의 OniBolt 발사. 근접을 피해 5칸 거리를 유지하며 3~4초 간격으로 사격 |

| **좀비 오니** | 체력 x0.7. **물기 100% 감염 + 감염 2배속**. 영하 기온에서 이동속도 -50% |
| **천수관음 오니** | 미니 보스 (예정). 감염이나 습격으로는 등장하지 않음 |

### 동물 변종
동물 감염 시 동물 변종의 가중치가 높으며, 인간도 낮은 확률로 변할 수 있습니다.

|---|---|

| **새우 오니** | 체력 1/2, 이동속도 6.0 c/s. **낚시 중 5% 확률**(예술 스킬 높으면 1%)로 낚싯줄에서 튀어나옴 |
| **비행 오니** | 이동속도 5.0 c/s |
| **해파리 오니** | 체력 x2. 낚시 중 튀어나옴 |
| **민달팽이 오니** | 근접 회피율 35% |
| **거미 오니** | 10초마다 가장 가까운 적에게 거미줄을 뿌려 이동 -70% (5초) |

### 메카노이드 변종
메카노이드의 감염은 100% 이 변종으로 진행됩니다.

**꼭두각시 오니** — 체력 x3, 메카노이드 상대 데미지 x2, 장갑(날카로움/둔기 40%)

## 오니 핵 (Oni Nucleus)

기형 오니가 파괴되면 남는 맥동하는 핵. **Anomaly의 살덩이 핵(Fleshmass Nucleus)과 이름·텍스처를 제외하고 모든 것이 동일**합니다 — 표면에 고기가 끊임없이 자라고(활동량에 따라 하루 20~120), 활동 단계별(A~F)로 그래픽이 변하며, 억제대에 얹어 활동량을 관리하고 연구로 지식 3을 얻을 수 있습니다.

유일한 차이: **활성화(활동량 100%)되면 살덩이 심장 대신 기형 오니로 자라납니다.**
방치하면 언젠가 지도에 기형 오니가 하나 더 늘어납니다. 처치하면 뒤틀린 고기 100~200과 파편 2가 남습니다.

## 도플갱어 (Doppelganger)

겉과 똑같은 가짜가 식구로 스며듭니다.

- **원정 복귀**: 정착민 1명(또는 "비무장" 2명)이 원정에서 돌아오면 **20% 확률**로 돌아온 정착민 중 하나가 도플갱어로 대체됩니다 (설정에서 끌 수 있음). 이동 중 **한 번이라도 잤으면 +10%**
  - 무장 판정: 무기를 든 정착민은 무장. Biotech 메카노이드는 **비전투형(lifter, constructoid, fabricor, agrihand 등)만 비무장**으로 인정. 동물은 **공격(해방) 또는 복종 훈련이 완료되면 무장**
  - **왕복선/드랍포드로 돌아오는 경우는 도플갱어 대상에서 제외**됩니다 (도보 원정만 위험)
- **크립조이너**: 크립조이너 합류 이벤트의 downside로 도플갱어가 등장할 수 있으며, **Void provocation 의식**으로 강제 소환할 수 있습니다
- **변신 조건**: 기분 10% 이하 / **과다출혈로 죽어가는 순간** / 그냥 사망했을 때 (시체 없이 오니가 일어남). 마취 등 단순 무력화로는 변신하지 않습니다
- **발각 시**: 외과 검사로 들키면 스스로 오니 감염이 진행되며(건강 탭에 표시) **1.5일 뒤 오니화**됩니다
- **치료 불가**: 감염 치료 수술을 시도하면 그 즉시 오니화합니다. (인류 재구성 의식으로만 되돌릴 수 있음)
- **오염**: 도플갱어가 **요리한 음식**을 먹거나, 도플갱어가 **집도한 수술**을 받으면 피해자는 반드시 오니에 감염됩니다

## 연구 — Anomaly 탭

| 연구 | 비용 | 효과 |
|---|---|---|
| 오니학 (오니의 기본) | 지식 5 | **오니 조우 후 연구 가능.** 실체 도감의 아오오니 페이지 해금 — 조우한 변종만 열람 |
| 아오오니 감염 검사 | 지식 10 | 외과 검사(바닐라 수술)에 오니 감염·도플갱어 탐지 해금 |
| 아오오니 치료 | 지식 20 | 감염 치료 수술 해금 (공업 의약품 4, 메카는 수리로 정화) |
| 조심스러운 낚시 | 지식 10 | 낚시 중 해파리/새우 오니 등장 확률 제거 |

오니 관련 연구는 **오니를 조우한 뒤**(도감에 아오오니가 등재된 뒤) 시작할 수 있습니다.

오니를 억제대에 얹고 연구하면 실체 지식을 얻을 수 있습니다.

## 의식 — 인류 재구성 (Human Reconstitution)

> 도플갱어는 아오오니가 인간으로 변한 것이라 치료할 수 없습니다. 하지만 파편을 바치고 공허의 설계도로 그 림을 통째로 재구성하는 방법은 있습니다.

| 항목 | 내용 |
|---|---|
| 선행 연구 | 아오오니 치료 |
| 제물 | 파편(Shard) 1개 |
| 대상 | 정착민 1명 |
| 준비/재사용 | 6시간 / 15일 |
| 성공 확률 | 의식 품질에 비례 (품질 0% → 35%, 50% → 70%, 90% → 95%, 100% → 100%) |

- **성공 시**: 대상의 모든 부정적 특성, 부상, 질병이 제거됩니다 (아오오니 감염 포함). 대상이 도플갱어라면 인간으로 되돌아갑니다.
- **실패 시**: 일반 정착민은 **소멸**하고, 도플갱어는 **즉시 오니화**합니다.

도플갱어가 의심되는 식구에게 마지막으로 시도해 볼 수 있는, 그리고 실패하면 목숨을 걸어야 하는 의식입니다.

## 이벤트

> **선행 조건**: 아래의 모든 오니 이벤트(습격, 감염, 도플갱어, 낚시 출현)는 **모놀리스 1단계(Stirring) 이상**에서만 발생합니다.

- **오니 습격**: 6일차 이후 스토리텔러가 무작위로 발생. 변종 구성은 전투 규모에 따름
- **Void provocation**: 의식으로 오니 습격 / 도플갱어 크립조이너 합류를 강제 발동 가능
- **호러 BGM**: 억제되거나 쓰러지지 않은 오니가 하나라도 있으면 바닐라/Anomaly BGM이 침묵하고 horror-b가 재생됩니다

## 구현 노트 (기획 대비 근사 항목)

- 멸치 오니의 "체력 50%에서 쓰러짐"은 고통 쇼크 임계값 0.5로 근사
- 블루베리 가스의 시각 효과는 모테 기반 (바닐라 가스 시스템은 확장 불가)
- 좀비 오니의 "탈출 주기 증가" 미구현
- 천수관음 오니는 미니 보스용 예약 정의 (디버그 스폰만 가능)
