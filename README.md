# Ao Oni (아오오니) RimWorld 모드

RimWorld 1.6 / Anomaly DLC용 아오오니 모드. `기획.txt` 기반으로 전체 구현되었습니다.

## 구성

- `Assemblies/AoOni.dll` — 빌드된 C# 어셈블리 (Harmony 패치 + 게임 로직)
- `Defs/` — 오니 인종 25종, 편종, 렌더 트리, 씽크 트리, 실체 도감, 연구/외과 검사, 헤디프, 데미지/투사체, 이벤트, 사운드
- `Textures/Things/Entity/` — 각 오니 방향별 텍스처 (단일 이미지는 3방향으로 복제됨)
- `Sounds/Music/horror-b.wav` — 오니 활동 중 루프 재생되는 호러 음악
- `Languages/Korean` — 한국어 번역 (DefInjected + Keyed)
- `Source/` — C# 소스. 빌드: `Source` 폴더에서 `dotnet build` (IFE 모드의 0Harmony.dll 참조)

## 구현 내용 (기획 대비)

### 공통
- 오니에게 상처를 입으면 70% 확률로 감염 (`Pawn.TakeDamage` Harmony 패치). 방어구가 데미지를 완전히 막으면 감염 없음 (체감 HP 감소 여부로 판정).
- 동물/메카노이드 감염 지원. 메카노이드 감염은 모드 설정에서 OFF 가능.
- 감염 후 3일(90,000틱 아님 - 180,000틱) 지나면 변이. 변이 4시간 전 `AoOniChanging` 헤디프로 피부 보라색 변화.
- 좀비 오니 공격은 100% 감염 + 감염 기간 1.5일(2배 속도).
- 실체 도감에는 아오오니 하나만 등록 (`EntityCodexEntryDef.AoOni`).
- "아오오니 감염 검사" Anomaly 탭 실체 연구(knowledgeCost 10) → 외과 검사 부활(의약품 2개)로 감염 확인. 미진단 감염은 건강 탭에서 `??`로 표시.

### 변종 (25종 전부 텍스처 연결)
일반: 아오오니(기본, 체력 걸신 x2), 4차원(텔레포트+5초 기절), 아메바(OniBolt 원거리, 사거리 20), 광대(자폭), 가지(처치 시 식자재 낙하), 납작(체력 1/4, 회피 40%), 푸왜티(멈춤→돌진 사이클), 허리디스크(2.5 c/s), 얼음(2.5 c/s, 영하 시 가중치 증가, 사망 시 허리디스크 부활), 부상(주기적 자해), 백개눈(1 c/s, 체력 x6), 기형(이동/억제 불가, 아오오니 생성), 뚱오니, 육손오니, 멸치 오니(체력 50%에서 쓰러짐 - PainShockThreshold 0.5 근사), 쉐로(공격력 2배), 좀비(저온 감속), 천수 오니(보너스 변종).
동물 변종: 박쥐, 새우(6 c/s), 비행, 해파리(체력 x2), 민달팽이(회피 35%), 거미(10초마다 거미줄 감속). 동물 감염 시 동물 변종 가중치 x4, 인간도 소량(0.3) 가능.
메카노이드 변종: 꼭두각시(체력 x3, 메카노이드 상대 데미지 x2). 메카노이드 감염은 100% 꼭두각시.

### 기타
- 억제되지 않고 쓰러지지 않은 오니가 존재하면 `AoOni_HorrorMusic` 사운드가 루프 재생됩니다 (게임 컴포넌트 Sustainer).
- 모드 설정: 기본 오니 확률 슬라이더(기본 30%), 메카노이드 감염 토글, 도플갱어 합류 토글.
- 도플갱어: 1명 또는 비무장 2명 원정 복귀 시 20% 확률로 숨은 헤디프 부여 → 기분 10% 이하 또는 쓰러짐 시 오니로 변신. 외과 검사로 발각 가능.
- 습격 이벤트 `AoOniRaid` (ThreatSmall, 6일차 이후)로 오니 그룹 스폰.

### 근사/차이점
- 멸치 오니 "체력 50%에서 쓰러짐"은 PainShockThreshold 0.5(고통 기반)로 근사.
- 좀비 오니의 "탈출 주기 증가"는 미구현 (감속만 구현).
- 푸왜티의 8칸 이동 감지는 40초 주기 멈춤+돌진 사이클로 근사.
- 잔여 검증 필요: 게임 내 렌더 트리/씽크 트리 로딩, 사운드 루프. 오류 시 로그(`[AoOni]` 접두사) 확인.
